# 领域资料

市、区、社区三级口腔防治机构使用**脱敏居民引用**上报检查（screening）、指导（guidance）和干预（intervention）记录。平台严格区分**人次**与**人数**：同一居民跨机构复诊产生多条人次，但去重后只算一人，避免“一百万人次”被直接当作服务人数而夸大儿童与老年人的实际覆盖范围。

## 不可逆引用

- 机构侧提交的 `resident_token` 必须是不含真实身份信息的不可逆引用。
- 平台落库前再做一次 `HMAC-SHA256(RESIDENT_PEPPER, token)`，库内只存摘要；因此即使库文件外泄，摘要也无法在本平台之外被反查或跨系统比对。
- 对外接口永远不返回 `resident_token` 或库内摘要，只返回聚合数字。
- 交换时间一律使用**带偏移量的 ISO 8601**（如 `2025-03-01T10:00:00+08:00`），无时区或不存在的日期（如 2 月 30 日）直接拒收。

## 只追加事实

`service_events` 是只追加事实表，数据库触发器禁止任何 `UPDATE`/`DELETE`。

- 迟到数据：`occurred_at` 很早、`received_at` 很晚才到达，直接作为新 `report` 事实进入。
- 更正与撤回：以 `fact_action=correction|retraction` 的**新事实**进入，并携带 `target_event_id` 指向**本机构**的原始 `report`；不能借更正触碰他机构事实。
- 有效口径：同一事实链（原上报与其更正/撤回）按接收时间取最新事实，撤回链不产出有效记录。
- 幂等：`(facility_id, idempotency_key)` 唯一，重放返回原事件编号，不产生新事实。

## 四类指标（口径由规则版本固定）

| 指标 | 口径 |
| --- | --- |
| `encounters` 人次 | 统计年内每条有效记录计 1，含全部质量标记 |
| `persons` 去重人数 | 有效合格记录按居民摘要去重，跨机构复诊只计 1 人 |
| `first_coverage` 首次覆盖 | 年内有合格记录，且年内首条合格记录之前 `first_visit_gap_days` 天内无任何合格记录（含他机构） |
| `continuous_management` 连续管理 | 年内至少 2 次合格服务，相邻间隔（含与上年末次服务的间隔）不超过 `continuity_window_days` |

`invalid` 等被规则版本排除的质量标记仍计人次，但不计入人员类指标。指标可按规则版本允许的维度（年龄组、服务类型、区）分组；人员级指标在同一维度值内判定。

## 年度冻结与修订

- 年度发布一次性固定**统计区间、规则版本、数据水位（`received_at` 上界）与贡献机构清单**，并把指标物化入库。
- 冻结之后到达的补报不能改动原版。再次发布同一年度会被拒绝（409）。
- 补报只能生成**修订版**：水位只能前进，修订版附带与父版逐格的 `from/to/delta` 差异说明、区间内新增事实数。原版指标与口径永久可查。

## 访问边界

| 角色 | 能力边界 |
| --- | --- |
| `facility` | 仅能以本机构身份上报，不能查聚合 |
| `district` | 聚合查询强制限定本区，任何参数都无法串查他区个体 |
| `city` | 全市聚合；不返回个体 |
| `research` | 同全市聚合；导出受最小分组规模约束 |
| `admin` | 登记规则版本、客户端与冻结发布 |

研究导出（`/v1/research/export`）时，只要**任一分组**（含合计）去重人数低于规则版本的 `min_cell_size`，整次导出被拒绝（422）；拒绝负载只给被抑制的维度键，不给人数，防止借拒绝信息反查居民。

## 可溯源

每个公开数字都随附：规则版本号 `rule_version_code`、数据水位 `watermark`（修订版另有父版水位）、贡献机构清单 `contributing_facilities`；发布与修订的创建时间、创建人同样留痕。据此可回答“这版数字采用了哪版规则、纳入了哪些机构在何时点之前的数据”，而数字本身无法被反向定位到居民。

接口字段约定见 `contracts/entities.json`，接口清单见 `README.md`。
